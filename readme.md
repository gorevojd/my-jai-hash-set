# my-jai-hash-set

Generic key-only hash sets for Jai, with configurable hashing and comparison.

## Dependencies

No other `my-jai-*` modules are required.

Jai standard library: `Basic`, `Hash`.

## Import

```jai
#import "my-jai-hash-set";
```

Add the directory containing `my-jai-hash-set` to the compiler's module search path.
